# Erebix Workspace Rules & Guidelines

## 1. Strict Tech-Stack & Implementation Auditing
- **No Assumptions**: Never write or update UI copy, architectural overviews, documentation, or landing pages based on assumptions or memory.
- **Audit Code First**: Before claiming any technology, model, library, or feature in UI/docs (e.g., ML models, databases, backend frameworks), **always inspect the source code first** (`backend/train.py`, `ml_engine.py`, `pom.xml`, `requirements.txt`, etc.) to verify what is actually implemented.
- **100% Truthfulness**: Ensure all text in the frontend, modals, dashboards, and README reflects the exact libraries and algorithms used (e.g., Python Tri-Model Stack: XGBoost + Random Forest + Scikit-Learn MLP Neural Network; Java Spring Boot 3.2.4 Gateway; Next.js 16).
